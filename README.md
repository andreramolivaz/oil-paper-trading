# Oil Paper Trading — Brent

Sistema di ricerca e **paper trading** sul Brent: motore Python su GitHub Actions, stato versionato sul branch
`data`, dashboard statica su GitHub Pages. Simulazione a scopo di studio: **nessun consiglio finanziario**,
nessun ordine reale.

Documentazione: `docs/BRIEF.md` (requisiti), `docs/PLAN.md` (piano e decisioni), `docs/DATA_SOURCES.md` (fonti).
Il README completo per l'utente verrà scritto nella fase 9.
